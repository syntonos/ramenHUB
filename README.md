## About
A USB hub in the shape of a ramen bowl; also contains a cat (and a fish)! USB-C upstream to 2 USB-A and 2 USB-C downstream. Uses a SL2.1s convertor. I did just want a USB hub, because I am quickly running out of ports. Might expand on this later: in built WIFI dongle? More diverse ports? Graphics card slot?
